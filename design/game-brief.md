**One-sentence pitch:** A steampunk pixel-art bullet hell where a young mechanic races
a bomb's countdown through four train wagons, beats O Maquinista and disarms the bomb
before the last train reaches Estação Zero.

## Core loop
- Enter a wagon → clear waves of automatons with twin-stick shooting, dash and steam pulse.
- Clearing the wagon opens the exit door → pick 1 of 3 upgrade cards (1 reroll per run).
- Move on to the next section; on entry the clock is clipped to that section's
  time target, so leftover time never removes the pressure.

## Player goal & fail state — what "working" looks like
- **Goal:** reach the cabin, beat O Maquinista's 3 phases, finish the disarm
  minigame before the clock hits 0, and see the ending.
- **Fail:** HP reaches 0 or the clock reaches 0 (bomb explodes). Either way, the player
  retries the current wagon from its checkpoint (upgrades kept, HP at least 3, clock
  restored to the time at wagon entry). **Confirmed intent:** forgiving checkpoints —
  the clock is the real pressure, and a run only ends when the player quits.

## MVP — what must exist to be the game (built, v1.4.0)
- Countdown clock with per-section time ceilings and difficulty scaling (easy/medium/hard).
- Player kit: aimed continuous fire, dash with i-frames, steam pulse, focus.
- 4 wagons with 6 enemy types (drone, sentinel, wrench, turret, sniper, freighter).
- 14 upgrade cards, 4 categories, common/rare/epic (60/30/10 weights).
- O Maquinista boss, 3 scripted phases with telegraphs and cutscenes.
- Bomb disarm minigame → ending → credits → results.
- Keyboard/mouse, gamepad and touch input; PC + Android builds.

## Out of scope — not building this
- No multiplayer — single-player only.
- No meta-progression — nothing carries between runs except settings.
- Portuguese only — no localization beyond `dialogue_pt_br.json`.

## Build order
The MVP is complete, and the source doesn't record the order it was built in. The play
order is: Boot → Menu → Boarding → Wagons 1–4 → Cabin → Boss → Disarm → Ending →
Credits → Results. New work is added as stories via `/create-stories`.
